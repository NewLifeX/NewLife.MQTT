NewLife.MQTT é um cliente e servidor MQTT 3.1/3.1.1/5.0 totalmente gerenciado com QoS, mensagens retidas, testamento, assinaturas compartilhadas e TLS.

## Instalação

```bash
dotnet add package NewLife.MQTT
```

## Início rápido

```csharp
var client = new MqttClient("tcp://127.0.0.1:1883");
await client.ConnectAsync();
await client.SubscribeAsync("test/#");
```

## Recursos

- Ampla cobertura de versões de protocolos e formatos
- Recursos de streaming e comunicação em tempo real
- Compatível com serviços de nuvem e middleware gerenciado
