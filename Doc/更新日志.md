# 更新日志（CHANGELOG）

## 发布基线
- 上一次发布版本：`v2.3.2026.0201`（`2026-02-01`）
- 本次统计范围：`2026-02-02` 之后至 `2026-07-15`

## 核心更新

### 1) 协议与功能增强
- 完善 MQTT 5.0 协议能力，增强服务端与客户端能力。
- 增加客户端 MQTT 版本显式指定能力，提升与不同 Broker 的兼容性。
- 新增 EMQX 共享订阅支持。
- 新增 SOCKS5 代理支持（`MqttClient.Socks5Server`），TCP/WS 连接可通过代理转发。
- 新增 OAuth 外部令牌认证。
- 新增 MQTT-SN v1.2 客户端与网关（23 种消息类型编解码、UDP CONNECT/PUBLISH/SUBSCRIBE/遗嘱/心跳）。

### 2) 集群与稳定性改进
- 修复集群相关缺陷并补充 MQTT 5.0 特性单元测试。
- 修正 `MqttController.OnConnect` 返回类型与基类签名一致性。
- 根据代码评审反馈补充异常日志，并优化管理服务测试端口策略（`Port=0`）。
- 完善集群自动发现与管理 API。
- 实现大规模集群路由：一致哈希分片（1024 分片 + 256 虚拟节点）、分片感知路由表、布隆过滤器订阅同步（1% 误判率）、批量合并转发管道（5ms/64KB 双阈值）。
- 实现热点主题自适应复制（10s 滑动窗口，副本因子 3→51 动态调整）。
- 实现多层分级拓扑管理（Edge/Regional/Core 三级）。
- 实现连接聚合网关（1000:1 聚合比）、订阅增量裁剪定向推送、分片全量快照恢复、路由降级自适应切换。

### 3) MQTT 5.0 协议完整性修复
- 修复 PubRec/PubRel/PubComp 缺少 V5.0 `OnRead`/`OnWrite` 导致的 ReasonCode + Properties 无法序列化的问题。
- 修复 SubAck 未解析 V5.0 Properties（将属性字节误解析为 GrantedQos）的问题。
- 修复 UnsubAck 缺少 V5.0 ReasonCodes + Properties 读写的问题。
- 修复 DisconnectMessage 缺少 V5.0 ReasonCode + Properties 读写的问题。
- 新增 `MqttMessage.ToPacket(MqttVersion)` 重载，支持 V5.0 上下文传递。
- 补充 12 个 V5.0 属性往返测试，全部通过。
- 修复 `Client_Error` 空方法，添加 `WriteLog` 记录底层传输异常。

### 4) 兼容性与工程能力提升
- 提升 .NET 多目标框架兼容性，优化异步与安全相关实现。
- 为 .NET 7/8 显式启用 QUIC 预览能力（`EnablePreviewFeatures`），保障相关功能可用。
- 升级核心依赖：
  - `NewLife.Core` 至 `11.13.2026.301`
  - `NewLife.Remoting` 至 `3.7.2026.302`
  - `NewLife.Stardust` 至 `3.7.2026.303`
- 多次执行 NuGet 包例行升级，持续保持依赖新鲜度。

### 5) 文档与元数据优化
- 更新分析报告与架构相关文档，统一传输端口说明，优化协议描述与规范。
- 优化项目元数据与包描述信息，提升分发可读性。
- 更新竞品分析 SOCKS5 状态（从 ❌ 改为 ✅）。
- 更新 README 传输计数（六种→七种），新增 SOCKS5 代理特性行。
- 新增 `Doc/功能清单.md` 追踪 83 个功能完成状态（100%）。
- 新增 `Doc/集成测试说明.md` 覆盖测试架构和运行方法。
- 新增 `Doc/M4-服务端架构.md`、`Doc/M6-集群架构.md`、`Doc/M6-集群竞品分析.md` 专项架构文档。
- 新增 `Doc/Benchmark/MQTT消息编解码性能测试.md` 和 MQTT 消息编解码性能优化报告。
